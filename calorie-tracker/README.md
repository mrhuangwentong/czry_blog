# 🔥 热量计算识别APP

一个桌面端Web应用，用于识别食物并计算热量、蛋白质、碳水化合物、脂肪等营养信息。

## ✨ 功能特性

### 📷 食物识别
- **AI图像识别模式**：上传或拖拽食物图片，模拟AI识别食物种类（模拟版本，随机返回食物结果）
- **手动选择模式**：从食物库中手动选择食物，快速查看营养信息
- 支持图片预览和移除

### 📊 营养计算
- 显示每100克食物的热量（大卡）
- 蛋白质、碳水化合物、脂肪三大营养成分详情
- 可视化营养进度条
- **份量调整**：支持1克到1000克的自定义份量
- 快捷份量按钮（50g/100g/200g/500g）
- 实时计算总热量

### 📋 历史记录
- 自动保存所有识别记录
- 按日期分组显示
- 每日摄入总热量统计
- 支持清空历史记录

### 📈 每日统计
- 环形进度图展示当日热量摄入进度
- 每日目标：2000大卡
- 蛋白质、碳水、脂肪每日摄入总量
- 支持查看历史日期数据
- 可删除单条记录

### 🍎 食物数据库
- **内置50种常见食物**
- 分类浏览：主食、肉类、蔬菜、水果、蛋奶、零食、饮料
- 搜索功能
- 点击食物可查看详细营养信息

## 🚀 使用方法

### 方式一：直接打开（最简单）
双击 `index.html` 文件，在浏览器中打开即可使用。

### 方式二：本地服务器（推荐）
在项目目录下启动一个本地HTTP服务器：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`

## 🎯 使用指南

### 识别食物
1. 在「识别」页面，选择识别模式：
   - **AI图像识别**：上传或拖拽食物图片，点击「开始识别」
   - **手动选择食物**：从食物分类中选择，或搜索食物名称
2. 查看识别结果和营养成分
3. 调整食物份量
4. 点击「记录摄入」保存到记录中

### 查看历史
- 点击底部「历史」标签，查看所有识别记录
- 记录按日期分组，显示每日总热量

### 每日统计
- 点击底部「统计」标签，查看当日营养摄入总览
- 使用左右箭头查看历史日期数据
- 点击删除按钮可移除单条记录

### 浏览食物库
- 点击底部「食物库」标签，浏览所有食物
- 使用搜索框快速查找食物
- 点击食物可查看详细营养信息

## 🍽️ 食物分类

- **主食类**：白米饭、馒头、面条、面包、饺子、包子、燕麦片、红薯、蛋炒饭、牛肉面
- **肉类**：鸡胸肉、牛肉、猪肉、红烧肉、鸡腿、鱼、虾、麻婆豆腐、宫保鸡丁
- **蔬菜类**：西兰花、西红柿、黄瓜、胡萝卜、白菜、菠菜、土豆、番茄炒蛋、炒青菜
- **水果类**：苹果、香蕉、橙子、葡萄、西瓜、草莓
- **蛋奶豆类**：鸡蛋、牛奶、酸奶、豆腐、豆浆
- **零食类**：巧克力、薯片、饼干、蛋糕、冰淇淋、花生
- **饮料类**：可乐、果汁、咖啡、奶茶、啤酒

## 💾 数据存储

应用使用浏览器的 `localStorage` 存储历史记录，数据保存在本地，不会上传到任何服务器。

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计（渐变、动画、响应式）
- **原生JavaScript** - 应用逻辑
- **LocalStorage** - 本地数据存储

纯前端实现，无需安装任何依赖，无需后端服务器。

## 📱 响应式设计

- 移动端：单列布局，底部导航
- 平板/桌面端：居中卡片式布局
- 支持拖拽上传和点击上传

## ⚠️ 说明

本应用的AI图像识别功能为**模拟版本**，上传图片后会随机返回一种食物的识别结果。如需真实的AI识别能力，需要接入计算机视觉API（如百度AI、腾讯AI、Google Cloud Vision等）。

营养数据来源于常见食物营养成分表，仅供参考，实际数值可能因品种、烹饪方式等因素有所差异。
